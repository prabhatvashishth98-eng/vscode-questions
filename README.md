## How to Compile and Run

You need a C compiler such as GCC installed on your computer.

1.  Clone or download this repository.

2.  Open the repository folder in VS Code or a terminal.

3.  Compile the required file:

    ``` bash
    gcc 1.c -o program
    ```

4.  Run the compiled program:

    **Windows (PowerShell):**

    ``` powershell
    .\program.exe
    ```

    **Linux/macOS:**

    ``` bash
    ./program
    ```

Replace `1.c` with the filename you want to compile.
